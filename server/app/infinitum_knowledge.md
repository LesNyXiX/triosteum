# Что такое Triosteum

Triosteum — экосистема для производственных компаний: всё, что нужно заводу для автоматизации и отчётности, в одном окне браузера.
Работает целиком в браузере; на сервере организации данные хранятся в базе, а несколько человек правят одно пространство одновременно.

## Пространства и среды

- **Пространство** — отдельный проект: своя доска, свои файлы, своя история версий. Пространства лежат в средах.
- **Среды**:
  - «Разработка» — доска блоков с кодом на HTML, Python, C++, C# и 1С. Блоки связываются стрелками в схему; данные идут по связям от блока к блоку. «Целостный код схемы» собирает бэкенд всей схемы.
  - «Офис» — документы как в Word, таблицы как в Excel (формулы, импорт и экспорт xlsx), презентации, формы, изображения, векторная графика. Плюс маршруты согласования: этапы, условия, выгрузки (Excel, CSV, пакет документов, почта, 1С).
  - Отраслевые среды: склад и логистика, производство (MES: сменные задания, OEE, простои, качество), финансы и бюджет (план-факт, платёжный календарь), персонал и табель, продажи и CRM, аналитика и дашборды. В них есть расчётные блоки и готовые примеры.
- Переключение сред — док внизу экрана или «Экосистема — все среды».

## Доска

- Блок добавляется кнопкой «Добавление элементов» (клавиша A) или из «Библиотеки плагинов» (L). Двойной клик открывает блок.
- Связь — потянуть от точки блока к другому блоку. Узел (связующая точка) объединяет несколько связей.
- «Конструктор» (B) выравнивает блоки по связям. «Вписать в экран» — F. Сетка — G.
- «Компиляция доски» (Ctrl+R) выполняет все блоки по порядку связей. Python выполняется на сервере в отдельном изолированном исполнителе.
- Поиск и команды — Ctrl+K. Отменить — Ctrl+Z, повторить — Ctrl+Y. Свои горячие клавиши задаются в Настройках (шестерёнка).
- У каждого блока есть ИИ-помощник: он пишет и правит код блока. «ИИ-архитектор» строит целую схему по описанию задачи.

## Совместная работа и сервер

- Организация, роли: владелец, редактор, согласующий, наблюдатель. «Команда…» в меню пространства — приглашения коллег.
- История версий пространства: «История версий…» в меню пространства.
- Администратор сервера: панель администратора (кнопка со щитом в шапке) — приглашения, пользователи, доступ, точки восстановления, журнал с отменой, задачи для ИИ.

## ИИ в Triosteum

Переключатель ИИ в шапке выбирает, кто отвечает во всех ИИ-функциях:
- **Infinitum** — собственный ИИ Triosteum, работает на сервере организации, без ключей и установки.
- **Локальный ИИ** — Ollama на компьютере пользователя, без интернета.
- **ИИ по API** — Claude по ключу Anthropic или любой сервис, совместимый с API OpenAI.
