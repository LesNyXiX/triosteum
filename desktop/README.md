# Triosteum для Windows

Приложение-окно Triosteum на Electron. При запуске — выбор режима (сменить: **Ctrl+Shift+M** или меню Triosteum → «Режим работы приложения…»):

- **Сервер организации** — открывает Triosteum с сервера (по умолчанию https://triosteum.ru): вход, команда, Infinitum.
  Сервер недоступен — приложение вернётся к выбору режима и скажет почему.
- **Без интернета** — встроенная копия Triosteum (`web/`, собирается из `src/`), данные хранятся на компьютере
  (папка `%APPDATA%\Triosteum`). Пространство можно сохранить в файл (Ctrl+S) и открыть на сервере.

В обоих режимах локальный ИИ (Ollama на этом компьютере) подключается без настройки `OLLAMA_ORIGINS`: приложение само
разрешает ему отвечать странице. Чужие ссылки открываются в обычном браузере. Новые версии приложение находит само
(GitHub Releases) и предлагает перезапуститься.

## Разработка

```bash
cd desktop
npm install
npm start          # собрать сайт и открыть приложение
npm test           # проверка (на Linux без экрана: xvfb-run -a npm test)
npm run dist       # собрать установщик (на Windows)
```

## Выпуск версии

1. Поднять `version` в `desktop/package.json` (через PR).
2. GitHub → Actions → «Приложение для Windows» → Run workflow → галочка «Опубликовать».
3. В Releases появятся `Triosteum-Setup-<версия>.exe` (установщик) и `Triosteum-Portable-<версия>.exe` (без установки).

Приложение не подписано сертификатом (это платно), поэтому при первом запуске Windows покажет «Windows защитила ваш компьютер» —
нажмите «Подробнее» → «Выполнить в любом случае».
